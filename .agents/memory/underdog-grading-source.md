---
name: Underdog grading source
description: Project rule for grading picks sourced from Underdog.
---

Use official Underdog settlement results as the source of truth for Underdog-native grading. Do not infer HIT, MISS, PUSH, or VOID from projected-line movement, disappearance, or unrelated player history.

**Why:** The user selected official Underdog settlement results as the grading source; market projections are not settlement outcomes.

**How to apply:** Integrate only a documented, authorized Underdog result feed or export with event/player/stat identity. If no such source is available, state that official grading is blocked and keep any existing third-party/stat-derived grading clearly distinct.
