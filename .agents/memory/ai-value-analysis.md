name: Evidence-bound AI value analysis
description: User-facing prop analysis should explain explicit line differences and directional history without inventing unavailable odds or value.
---

The AI analysis block is advisory presentation only: compare only supplied provider lines and odds, frame value from the actual OVER/UNDER direction, show L10/H2H/season support, and label missing comparison data instead of making an odds-backed claim.

**Why:** The desired analysis is useful because it explains why a lower or higher line may create value, but unsupported sportsbook context would make the alert misleading.

**How to apply:** Reuse existing observations and persisted evidence in alert formatting; keep new provider fetching and delivery qualification outside this presentation layer.
