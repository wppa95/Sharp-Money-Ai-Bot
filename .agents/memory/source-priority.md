## Rule
PrizePicks → Underdog → DraftKings/FanDuel (MLB ML/Totals only)

**Why:** User stated PrizePicks is their primary daily-use source. Sportsbook alerts are tertiary. Do not start sportsbook optimisation work until PrizePicks analysis pipeline is considered complete.

## How to apply
- When proposing or scoping new tasks, lead with PrizePicks improvements.
- Underdog enhancements are acceptable second-priority work.
- DraftKings/FanDuel work (even within the approved MLB ML/Totals scope) comes last.
- If a feature request is ambiguous (e.g. "improve alert quality"), default to implementing it on the PrizePicks path first.
