CORE OBJECTIVE

The fundamental purpose of this bot is to maximize data collection continuously, across ALL supported sports and ALL available relevant data sources/markets, without unnecessarily leaving available data uncollected.

This is NOT a single-sport monitoring system.

19. Identify any bottleneck that prevents maximum practical data collection.

IMPORTANT ARCHITECTURAL REQUIREMENT

The goal is NOT to force every sport to return data every cycle.

The goal is:

Continuously attempt to collect as much valid, relevant data as the available providers expose across all supported sports and markets.

If a sport has no available data, that is fine.

If a sport has available data but the application is not requesting/processing it, that is a problem.

If a provider has data but downstream logic unnecessarily discards it, identify that separately.
