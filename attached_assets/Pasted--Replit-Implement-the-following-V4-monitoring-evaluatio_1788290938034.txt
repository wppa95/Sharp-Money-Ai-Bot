## 2. Every material line movement must trigger a complete fresh evaluation

For every material Underdog line movement:

Current line
→ current game-level historical evidence
→ current edge
→ current direction
→ current quality
→ current reason
→ current PLAY qualification

Requirements:
- Invalidate the previous evaluation when the line materially changes.
- Recalculate against the NEW line before persisting or delivering anything.
- Do not reuse an old-line evaluation merely because the player/stat identity is unchanged.
- Do not reuse old-line hit rates, edge, quality, reason, or direction.
- A line movement is an evaluation trigger, NOT a betting direction.

Examples:
- 0.5 → 1.5 can produce OVER 1.5 OR UNDER 1.5.
- 1.5 → 0.5 can produce OVER 0.5 OR UNDER 0.5.
- 4.5 → 3.5 can produce OVER 3.5 OR UNDER 3.5.

Direction must come from fresh evidence against the NEW line.

## 3. Historical evidence must be calculated against the CURRENT line

For every evaluation:
- L5/L10/L20/L30 must be calculated against the current Underdog line.
- If the line changes, recalculate historical hit rates for the new line.
- Never carry over hit rates calculated against the previous line.
- Never let old-line evidence leak into a new-line PLAY.
- The reason must also be generated from the current-line evidence.

Example:
If a prop moves 0.5 → 1.5, determine how many actual completed games cleared 1.5. Do not reuse the 0.5-line hit rate.

## 4. History must use actual game-level player results

Separate player performance history from line/polling observations.

L5/L10/L20/L30 must use:
- actual completed games
- actual player-stat results
- valid game-level outcomes

Do NOT treat line snapshots, polling observations, provider observations, repeated scans, or tracking records as separate games.

Sample-size rules:
- If 5 valid games exist → L5 is valid.
- If 10 valid games exist → L10 is valid.
- If 15 valid games exist → L15 is valid.
- If only 15 valid games exist, L20/L30 must be reported as insufficient.
- Denominators must equal actual valid completed games.
- Never display L20/L30 using an L10/L15 denominator.
- Never call a collection of snapshots a “30-game sample.”

If only 16 valid games exist, do not fabricate L20/L30.

## 5. Current-line evidence integrity

For each evaluation, verify that player, sport, market/stat type, current line, completed game result, OVER/UNDER comparison, hit rate, edge, direction, quality, and reason all belong to the same evaluation snapshot.

Do not combine:
- current line + old-line history
- new line + old edge
- new line + old reason
- new line + stale direction

The Telegram feed should represent actionable PLAYs only.

A Telegram PLAY must have ONE user-facing actionable classification.

ACTIONABLE and STRONG BET must NOT both be displayed as separate labels for the same PLAY.

Use the existing PLAY strength/tier logic internally, but keep Telegram presentation clean.

For a qualified PLAY:
- Show the actual PICK.
- Show the existing Quality score.
- Show STRONG BET when that is the existing user-facing classification.
- Do NOT additionally display ACTIONABLE.

ACTIONABLE may remain an internal database/population/state classification, but it must NOT be rendered as a separate Telegram label.

Do not expose internal routing/state terminology such as ACTIONABLE as an additional user-facing Telegram classification.
