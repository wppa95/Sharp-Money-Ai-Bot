4. MAKE LINE MOVEMENT MORE INTELLIGENT

Do not treat every line movement as equally meaningful.

Analyze:

Direction

Did the market move toward OVER or UNDER?

Magnitude

How large was the move?

Velocity

How quickly did it move?

Persistence

Did the new line remain?

Reversal

Did the line subsequently move back?

Context

When available, identify whether movement appears related to:

* Injury/news
* Role/minutes
* Starting status
* Matchup
* Market adjustment
* Possible overreaction
* Other available contextual information

Example:

4.5 → 9.5

must be recognized as materially different from:

10.5 → 11.0

The objective is to identify meaningful market information, not simply detect that a number changed.

5. ADD CURRENT-LINE VALUE ANALYSIS

This is one of the most important upgrades.

The bot must distinguish:

“The line moved.”

from:

“The current line still has value.”

Where sufficient data exists, estimate an internal model projection/fair line.

Example:

Model projection: 6.8

Current Underdog line: 9.5

Model edge: +2.7

That should influence the decision.

The model should answer:

“Is the current line still mispriced?”

not simply:

“Did the line move?”

Do not chase a move after the value disappears.

If projection/fair-line data is unavailable, explicitly record it as unavailable.
