TASK — Track ALL evaluated player prop opportunities

Do not only track recommended plays.

Track:

1. PLAY decisions
- Props the bot recommends

2. PASS decisions
- Props the bot evaluates but does not recommend

Reason:
The bot needs to learn when it was correct to pass and when it missed profitable opportunities.

Example:

Bot:
PASS ❌

Player clears line easily:
3/4 hits

The system should record that as a missed opportunity.

---

For every evaluated prop, store:

- player
- sport
- market/stat type
- line
- over/under selection
- Underdog source
- confidence score
- tier
- recommendation:
  - PLAY
  - PASS
- timestamp
- game/event information when available

---

After the game/event finishes:

The system should:

1. Wait until the event is complete

2. Retrieve final player statistics

3. Compare the actual result against the selected line

4. Grade every evaluated opportunity:

✅ Hit

❌ Miss

➖ Push (when applicable)

---

For recommended PLAY decisions, track:

- total plays
- hits
- misses
- pushes
- hit rate

---

For PASS decisions, track:

- total passes
- how many would have hit
- how many would have missed
- missed opportunities
- correct passes

---

Create performance analytics for future development:

Track results by:

- sport
- market/stat type
- tier
- confidence range
- line value
- player
- PLAY vs PASS

Examples of questions this data should eventually answer:

- Are high confidence picks actually performing?
- Are A-tier picks better than B-tier?
- Is the model too conservative?
- Are we passing on profitable opportunities?
- Which markets are strongest?
- Which markets should be avoided?
