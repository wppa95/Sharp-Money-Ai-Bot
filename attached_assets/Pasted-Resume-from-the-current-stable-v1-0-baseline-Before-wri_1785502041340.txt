❌ Prop Removed

Only alert when the prop was previously tracked.

Do not send removal notifications for props the bot never saw.

Include:

* Player
* Prop
* Last known line
* First seen time
* Last seen time
* Duration available
* Removal reason if determinable

Possible reasons:

* Game started
* Line adjustment
* Temporary removal
* Permanent removal
* Unknown

Notification format:

🚨 PrizePicks Prop Removed

Player:
Prop:
Last Available Line:
First Seen:
Last Seen:
Time Available:
Status:
Removed from PrizePicks

Reason:
<Game Started / Line Adjustment / Temporary Removal / Unknown>

Do not guess reasons if they cannot be determined.
