==================================================
CORE ARCHITECTURE

PrizePicks and Underdog remain completely separate betting providers.

PropLine is a shared supplemental sports-data source.

PRIZEPICKS
actual PrizePicks line
↓
PropLine supplemental data
↓
existing analysis

UNDERDOG
actual Underdog line
↓
PropLine supplemental data when useful/missing
↓
existing analysis

PropLine MUST NOT replace the actual provider identity or actual sportsbook line.

For Underdog:

* Underdog remains authoritative for the Underdog line.
* Underdog remains authoritative for Underdog market identity.
* Underdog remains authoritative for Underdog provider identity.
* Underdog remains authoritative for Underdog movement/state.
* PropLine supplements missing/useful information.
* Never silently convert a PropLine line into an Underdog line.
* Never merge PrizePicks and Underdog into one provider.
