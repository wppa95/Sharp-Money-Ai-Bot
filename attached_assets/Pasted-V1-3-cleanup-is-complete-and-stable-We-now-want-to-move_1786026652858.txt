PART 1 — Improve multi-sport actionable picks

* Other sports are producing market movement but fewer qualified picks.

Goal:
The bot should not become MLB-only.

All supported sports should have the opportunity to produce actionable picks when a real edge exists.

Analyze the funnel:

raw → parsed → movement detected → scored → gated → actionable

Review:

* MLB
* NBA/WNBA
* NFL
* Soccer
* CS
* COD
* DOTA
* Other supported sports

Determine where sports are dropping off.

Examples:

If movement_detected is low:

* Data quality issue
* Not enough market activity

If movement_detected is high but actionable is low:

* Scoring/gating issue

If historical data is weak:

* Confidence calculation issue

Do not lower standards just to create more picks.

Before changing anything:
Report findings.

* Fantasy projections

* Line movement information

Do not add paid APIs unless specifically approved.

Research and evaluate free/public sources first.

Priority:

1. Sleeper Picks
2. PrizePicks (only if a reliable accessible method exists)
3. Betr
4. ParlayPlay
5. Chalkboard

For each source evaluate:
