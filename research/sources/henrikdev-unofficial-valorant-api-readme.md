# HenrikDev unofficial Valorant API README

URL: https://github.com/Henrik-3/unofficial-valorant-api (README)  
Retrieved: 2026-09-26 via GitHub raw content.

The repository calls itself an “Unofficial VALORANT API using the VALORANT Ingame API”. Its README requires user consent for use of user data, describes API-key access, and states 30 requests/minute for Basic keys and 90 requests/minute for Advanced keys (with custom limits handled separately). It says public Discord bots need an Enhanced key and warns that the API is not intended for large analytic projects; the README also says the service is not intended for production use absent an individually justified arrangement.

This is useful evidence for access/rate-limit constraints, not authorization. It is not Riot's official API, and the README does not establish a professional-esports/tournament archive or a match-by-ID route for tournament games. Treat its match-history data as ordinary player/account history unless the provider explicitly documents otherwise. A GitHub repository's public visibility does not grant a bot license.
